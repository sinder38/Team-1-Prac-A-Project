# Calibration Scoring Rule

This is the scoring table used by R10 for calibration.

| Confidence | Direction correct? | Score |
| --- | --- | ---: |
| High | Correct | +3 |
| Medium | Correct | +2 |
| Low / Uncertain | Correct | +1 |
| High | Wrong | -2 |
| Medium | Wrong | 0 |
| Low / Uncertain | Wrong | +1 |
