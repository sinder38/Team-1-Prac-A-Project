Definition of Done (DoD)

The team agreed that a task is complete when:

- The assigned work has been completed.
- Code has been committed to GitHub.
- A Pull Request has been reviewed and approved.
- GitHub Actions and CI checks pass successfully.
- Documentation has been updated.
- Testing and validation have been completed.
- The work is ready for integration and presentation.


Team Working Agreements

For Sprint 6, the team agreed to:

- Communicate mainly through the shared team channel.
- Update GitHub and FigJam regularly.
- Share progress during Daily Standups.
- Raise blockers as early as possible.
- Review Pull Requests before merging.
- Support teammates whenever needed.

- Follow the Sprint Goal and Definition of Done throughout the sprint.
