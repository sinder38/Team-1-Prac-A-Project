Sprint 5 Retrospective
What Went Well
The team successfully progressed toward the Sprint 5 goal of achieving a more automated pipeline.
Multiple project components were completed, including the Delta Engine, Evidence Agent, Human Score review, testing activities, and frontend development.
Automation continued to reduce manual work and improved overall workflow efficiency.
QA and validation activities helped ensure outputs were generated correctly and followed project requirements.
Team members adapted well to feedback and made improvements when issues were identified.
The presentation strategy was successfully aligned with the project's technical achievements and sprint goals.
GitHub workflows, code reviews, and pull request processes continued to support development activities.
Challenges Faced
Several tasks depended on outputs from other team members, causing delays in some areas.
Some requirements became clearer only after development had already started, resulting in rework.
Limited development time, especially with much of the work being completed during weekends.
Backend integration proved more complex than initially expected and could not be completed during this sprint.
Testing and validation activities required additional effort to understand output formats and dependencies.
Some communication continued through direct messages rather than shared channels, reducing visibility across the team.
What We Learned
Early clarification of requirements helps reduce rework and misunderstandings.
Regular communication between roles is important when tasks depend on each other.
Feedback and review processes improve both code quality and project outcomes.
Human review remains important even when AI-generated outputs are available.
Large technical tasks should be broken down and planned carefully to avoid late sprint pressure.
Actions for Next Sprint
Improve communication through shared team channels.
Raise blockers earlier when issues are identified.
Clarify task requirements before development begins.
Improve testing quality and validation coverage.
Continue improving integration between project components.
Allocate more time for complex development tasks such as backend integration and database migration.
Increase collaboration between technical, QA, and presentation roles.
