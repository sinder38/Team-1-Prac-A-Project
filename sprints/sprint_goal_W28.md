Sprint Goal — Team 1A, Week 28

This sprint's primary goal is to close out the engineering work that has been carried across several sprints and get the pipeline running end-to-end with a merged, integrated system. Both the delta engine and macro engine graph generation have been in progress for multiple sprints — this sprint they need to land as merged, working code, not drafts.

By end of sprint, the team should have:
- The delta engine merged and comparing the previous sprint's prediction against actual market data to inform the next prediction
- Macro engine graph generation merged and producing usable output
- The backend web server and frontend integrated and merged into a single working system
- The full pipeline running successfully end-to-end, from data collection through to prediction artifact
- At least 2 of the 4 agents ( Almanac, Technical ) fully tested
- Every team member visibly participating in the sprint's work, not just the usual few

The definition of done still includes the full prediction artifact (SPX, NDX, IWM direction, range, confidence), all four LLM responses in the evidence folder, Human Score table completed, chart screenshots committed, and a release tag before class.

This sprint is about convergence: several long-running workstreams (delta engine, macro engine, frontend/backend integration) need to actually merge this sprint rather than slip again, and the team needs a pipeline that runs cleanly from end to end as proof the pieces fit together.
