What went well?
Team continued improving existing features instead of introducing unnecessary new functionality.
Database local storage and pipeline updates were successfully integrated.
Weekly pipeline ran successfully after identifying suitable free LLM models.
Team members collaborated on deployment ideas and GitHub Wiki documentation.
Merge conflicts were identified early and developers were reminded to resolve them before merging.
README documentation was reorganized and simplified for better usability.
Presentation preparation started early with coordination between technical members and the presenter.

What problems did we face?
Some tasks required clarification because responsibilities changed during the sprint (e.g., Markdown documentation changed to GitHub Wiki).
Limited availability of free LLM models required additional investigation and model replacement.
Some PRs required further review before they could be merged.
Merge conflicts delayed integration across several branches.
A backend API configuration issue (NEWSDATA_API_KEY) affected the Macro Agent.
Some team members had limited availability because of internship commitments or multiple assignment deadlines.
Communication about current task priorities occasionally caused confusion, requiring additional clarification.

Learnings & Action Items
Clearly communicate task changes whenever priorities are updated.
Confirm assigned responsibilities after new tasks are introduced.
Resolve merge conflicts as early as possible to avoid blocking integration.
Review PR feedback promptly before requesting another review.
Continue documenting the project using GitHub Wiki for easier maintenance.
Continue monitoring free LLM availability and prepare backup model options.
