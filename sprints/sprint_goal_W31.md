Sprint Goal — Team 1A, Week 31

This sprint's primary goal is to take the working end-to-end pipeline public: deploy the website to the web, finalise the frontend, fix the remaining Delta Engine artifact bugs, and reorganise the codebase so the project is presentable, maintainable, and reproducible.

By end of sprint, the team should have:
- The website deployed to the web and reachable at a public URL, with the server pipeline wired up correctly (slug/routing fixes) and admin-authenticated access where needed
- The frontend finalised 
- The Delta Engine artifact bug fixed
- The codebase reorganised and hardened

The definition of done still includes the full prediction artifact (SPX, NDX, IWM direction, range, confidence), all four LLM responses in the evidence folder, Human Score table completed, chart screenshots committed, and a release tag before class.

This sprint is about delivery and polish: after W30 consolidated the data layer and prediction range, W31 focuses on shipping the product to the web, locking down the frontend with CI, closing out the Delta Engine artifact defects, and tidying the codebase so the system is ready to demo and hand over.
