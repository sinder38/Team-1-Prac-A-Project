Sprint Goal — Team 1A, Week 25

This sprint's primary goal is to deliver a functioning backend web server and get the evidence agent running fully autonomously through the GitHub Bot - no manual intervention. The evidence agent was planned last sprint but never merged; that changes this sprint.

By end of sprint, the team should have:
- The evidence agent merged and running autonomously, with all output provisioned via GitHub Bot PR
- A backend web server with basic capability integrated into the prediction pipeline
- A frontend mockup presented to the Product Owner (draft, not production-ready)
- The delta engine in place - comparing the previous sprint's prediction against actual market data to inform the next prediction
- The Almanac and Technical agents each passing at least 5 integration tests

The definition of done still includes the full prediction artifact (SPX, NDX, IWM direction, range, confidence), all four LLM responses in the evidence folder, Human Score table completed, chart screenshots committed, and a release tag before class.

This sprint also marks the team's transition to a structured role-based workflow, where development, QA, presentation, human report, and Scrum responsibilities are clearly separated. Success means the bot does the heavy lifting, developers focus on building, and non-dev roles contribute meaningfully to the final deliverable without blocking each other.
